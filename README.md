# Love Heart

An animated heart made of "Ashyy", for browsers and the Python desktop.

## Preview the website

Open index.html in your browser. Keep heart.js in the same folder. No installation is needed.
Change the phrase in heart.js to personalize it, and update the title and canvas label in index.html.

## Publish with GitHub Pages

1. Commit and push index.html and heart.js to your GitHub repository.
2. Open the repository on GitHub and go to Settings > Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Choose the branch containing the files (usually main) and / (root), then Save.
5. Wait for deployment, then copy the published URL shown on the Pages settings screen.

The address usually looks like https://YOUR-USERNAME.github.io/REPOSITORY-NAME/.
Recipients can open the link on their phone or computer without Python.

## Run the desktop app

```bash
python love.py
```
